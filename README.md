# Arouja Birthday Site 🍓

Premium static GitHub Pages website for Arouja / Areej birthday.

## Password
`30/8`

## Main features
- Password gate
- Birthday intro and countdown to 30/8/2026
- Story beginning on 5/3/2026
- Long Egyptian-Arabic birthday letter
- Hidden love confession game
- Local photo picker (images stay on the visitor's device)
- Embedded song and custom player
- WhatsApp reply button
- Mobile-friendly effects and animations

## Important files
- `index.html` → main website
- `kol-sana.mp3` → song file; keep it in the root beside `index.html`
- `404.html` → custom not found page
- `assets/favicon.svg`
- `assets/preview.svg`
- `.nojekyll`

## GitHub Pages
Upload all files inside this folder to the repository root.
Then open:
`Settings → Pages → Deploy from a branch → main → / (root)`
